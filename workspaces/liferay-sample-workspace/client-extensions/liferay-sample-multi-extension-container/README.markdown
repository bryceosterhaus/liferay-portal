# liferay-sample-multi-extension-container

This is project that contains multiple client extensions that share a single container.

## Client Extensions Included

- header-liferay-sample-multi-extension-container (Custom Element)
- sidebar-liferay-sample-multi-extension-container (Custom Element)
- fds-cell-liferay-sample-multi-extension-container (FDS Cell Renderer)
- spritemap-liferay-sample-multi-extension-container (Theme Spritemap)

## Shared Resources

This project also contains shared resources and dependencies across each client extension.

- `underscore`(npm module)
- `shared-utils`(code in `./src/shared-utils`)
